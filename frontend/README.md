# Frontend (Vite + React + TypeScript)

Quick start for the frontend scaffold created by the assistant.

Install dependencies:

```bash
cd frontend
npm install
```

Start dev server:

```bash
npm run dev
```

Notes:

- The app runs in `mock` mode by default. Set `VITE_APP_MODE=aws` to prepare wiring for AWS providers.
- This scaffold includes a basic `GeminiProvider` simulation and placeholder `BedrockProvider`.
